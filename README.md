# 复制Mi达 (superMi)

一个基于 LSPosed 的 Android 模块：复制任意内容后，自动识别其中的网址、平台口令、手机号、快递单号、地址等，并在屏幕顶部弹出悬浮气泡，点击即可跳转到对应 App。


---

## 功能简介

- **复制即识别**：在任意 App 复制内容，自动识别类型并弹出气泡，无需手动操作
- **支持识别类型（可自定义添加）**：

| 类型              | 示例                                  | 跳转目标（可自定义）           |
|-----------------|-------------------------------------|----------------|
| 网址 URL          | `https://example.com`               | 浏览器      |
| 平台口令/链接 | 淘宝/闲鱼/京东/拼多多/小红书/抖音/B站/网盘口令/......  | 对应平台 App |
| 手机号             | `13800138000`                       | 拨号             |
| 快递单号            | `YT1234567890` / `EMS...` / `JD...` | 菜鸟 / 京东        |
| 地址              | 省市区 + 道路门牌                          | 地图       |

- **悬浮气泡**：最多并排 3 个 App 图标，默认5秒自动消失（可调），支持位置、间距、图标大小、背景透明度自由调节
- **截图气泡**：将系统截图分享给「复制Mi达」后，在屏幕上暂存截图缩略图；点击气泡可展开查看、缩放、翻页和管理截图
- **深链直达**：支持 App Links 的平台一键跳转详情页；不支持的平台仅启动 App，由 App 自行解析口令
- **规则可配置**：平台识别规则、号码识别规则均可增删改
- **配置备份迁移**：一键导出 / 导入全部设置，跨设备迁移

## 安装步骤

1. 安装 APK
2. 打开 LSPosed，启用「复制Mi达」模块
3. 作用域勾选 **系统框架**（System Framework）
4. **重启设备**

重启后即可使用。打开 App 可进行个性化设置。

> 更新模块后，部分功能需要重启设备才生效。

## 使用说明

### 基本使用

1. 在任意 App 复制一条内容（如淘宝口令、手机号、快递单号、地址、链接）
2. 屏幕顶部自动弹出悬浮气泡，显示可打开的 App 图标
3. 点击图标即可跳转到对应 App

### 截图气泡

截图气泡用于暂存需要短时间反复查看的截图，例如取餐码、取件码或订单页面，不需要重新打开相册查找。

1. 在任意 App 截屏
2. 在系统截图预览或分享面板中点击「分享」
3. 选择「复制Mi达」
4. 截图会以缩略图气泡显示在屏幕边缘；最多保留 1～3 张，最新截图位于右侧
5. 点击缩略图进入查看框

查看框支持以下操作：

- 左右快速滑动切换截图；
- 双击、双指缩放和拖动查看细节；
- 单击图片显示或隐藏底部操作栏；
- 上滑、系统返回键或关闭最后一张截图退出查看框；
- 点击「取消展示」删除当前暂存截图；
- 点击来源 App 图标可打开截图来源应用；
- 点击「保存到相册」可保留相册原图，或点击「删除相册图片」删除原图。

按 Home 返回主页时，查看框会退出并恢复截图气泡，方便稍后继续查看。

### 截图气泡设置

在「复制Mi达」App 的「截图气泡」设置中可以配置：

- **最多显示张数**：1～3 张，超过上限时淘汰最旧截图；
- **关闭方式**：一直开启，或按设定的 15～600 秒定时关闭；
- **自动删除相册原图**：仅处理系统截屏目录内、分享后仍在设定时限内的截图；默认 6 小时，可选 1/3/6/12 小时；
- **系统截屏目录**：可手动选择特殊机型使用的截图目录；
- **来源返回后**：从来源 App 返回时关闭查看框，或回到查看框；
- **查看框背景**：默认「普通」黑底，也可切换为白色透明模糊背景；Android 12+ 支持系统跨窗口模糊，不支持时自动降级；
- **气泡位置**：截图气泡与复制气泡共用位置设置，并会在复制气泡出现时自动让位。

截图气泡与复制气泡是两条独立流程：复制内容仍按原有规则识别，截图需要通过系统分享面板明确分享给「复制Mi达」。

### 设置界面

打开「复制Mi达」App，可配置：

- **气泡位置**：1/2/3 个图标分别可调位置，支持方向键微调与一键复位
- **图标大小 / 背景透明度 / 图标间距 / 停留时间**：滑块调节
- **各类型 App**：地图、浏览器、拨号 App 可选（最多 3 个，默认自动匹配）
- **识别规则**：管理平台口令规则、号码规则（开头 + 位数）
- **识别长度上限**：超过长度不识别（防止长文本误判）
- **调试开关**：开启后输出日志，便于排查问题

### 配置备份与迁移

- 主页「其他」板块 → **导出配置**：将全部设置保存为 `.txt` 文件
- **导入配置**：选择备份文件即可恢复设置

## 常见问题

- **位置和我设的不一样**：如预览里选的3个图标下，设置的位置仅对同时出现3个App的气泡窗生效。2个或1个图标需单独设置
- **点击后打开的不是搜索结果页**：部分平台（如抖音）限制，短视频可直达但如购物链接等会错误识别，需要根据自己使用需求进行取舍，大部分app本身设计的有识别自家内容方式，所以“仅打开”其实效果也不错。
- **想换 App**：在设置中为对应类型重新选择 App 即可，无须重启
- **截图气泡不显示**：确认截图是通过系统分享面板发送给「复制Mi达」，并确认 LSPosed 已启用系统框架作用域。涉及 `system_server` 的截图气泡代码更新后，需要重启系统框架或重启设备；普通 App 侧更新安装后即可生效。
- **查看框背景或系统栏颜色异常**：截图查看框使用透明窗口和 edge-to-edge 布局，不同 Android/HyperOS 版本对跨窗口模糊支持不同；设备不支持时会自动使用透明层降级。
