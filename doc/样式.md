# 样式记录：顶部「刷新列表」毛玻璃按钮

> 记录主界面顶部右侧「↻刷新列表」按钮的实现方式和可复现配方。
> 当前核对日期：2026-08-30。

## 效果位置

“复制Mi达”主界面顶部右侧，文字为 `↻刷新列表`。它看起来像一块半透明毛玻璃，实际是**蓝色渐变头部 + 半透明白色玻璃片**的叠加效果，并非实时背景模糊。

## 实现原理

视觉上的“毛玻璃”由三层组成：

1. 头部 `header` 使用蓝色渐变背景，作为玻璃片后面的“彩色环境”。
2. 按钮自身用 20% 白色填充 + 40% 白色描边，形成半透明玻璃片主体。
3. 白色文字直接压在渐变上，保留清晰的 1dp 描边与圆角，看起来像磨砂材质。

这不是系统级模糊（没有 `RenderEffect` / `FLAG_BLUR_BEHIND`），所以兼容性和性能都更稳，改起来也简单。

## 涉及文件

| 文件 | 作用 |
|---|---|
| `app/src/main/res/layout/activity_main.xml` | 顶部 `header` 与按钮 `btn_refresh_apps` 的布局 |
| `app/src/main/res/drawable/bg_btn_header.xml` | 按钮的半透明玻璃片背景 |
| `app/src/main/res/drawable/bg_header_gradient.xml` | 头部的蓝色渐变背景 |
| `app/src/main/res/values/colors.xml` | `accent` / `accent_2` / `white` 颜色 |

## 按钮布局（当前实现）

`activity_main.xml` 中 `btn_refresh_apps`：

```xml
<TextView
    android:id="@+id/btn_refresh_apps"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:background="@drawable/bg_btn_header"
    android:clickable="true"
    android:focusable="true"
    android:gravity="center"
    android:minWidth="0dp"
    android:minHeight="0dp"
    android:paddingStart="11dp"
    android:paddingEnd="11dp"
    android:paddingTop="6dp"
    android:paddingBottom="6dp"
    android:text="↻刷新列表"
    android:textColor="@color/white"
    android:textSize="12sp" />
```

关键点：

- 用 `TextView` 而不是 `Button`，避免系统按钮默认高度、水波纹和 `stateListAnimator` 干扰。
- 必须写 `clickable="true"` / `focusable="true"`，否则纯 `TextView` 默认不可点击。
- `minWidth="0dp"` / `minHeight="0dp"`，让尺寸完全由文字和 padding 决定。
- 文字 12sp 白色，padding 左右 11dp、上下 6dp，整体偏紧凑。
- 当前没有 `includeFontPadding="false"`，若以后改成它，按钮高度会更矮、字体会更贴边。

## 玻璃片背景（核心配方）

`bg_btn_header.xml`：

```xml
<?xml version="1.0" encoding="utf-8"?>
<shape xmlns:android="http://schemas.android.com/apk/res/android"
    android:shape="rectangle">
    <solid android:color="#33FFFFFF" />
    <stroke
        android:width="1dp"
        android:color="#66FFFFFF" />
    <corners android:radius="12dp" />
</shape>
```

参数对应关系：

| 参数 | 值 | 效果 |
|---|---|---|
| 填充色 | `#33FFFFFF` | 20% 白色（约 0x33 / 0xFF），半透明玻璃主体 |
| 描边色 | `#66FFFFFF` | 40% 白色（约 0x66 / 0xFF），玻璃边缘反光 |
| 描边宽 | `1dp` | 细边，突出“切片”感 |
| 圆角 | `12dp` | 柔和胶囊状，避免生硬直角 |

调整建议：

- 玻璃感更强：把填充 `#33` 提高，例如 `#4DFFFFFF`。
- 更淡更克制：降低填充，例如 `#1FFFFFFF`。
- 描边明显：把 `#66` 提高，或把宽度从 `1dp` 加到 `2dp`。
- 更圆润：圆角从 `12dp` 改为 `16dp` 或更高。

## 复用：白色气泡的毛玻璃边框

白色气泡开启“边框条”时直接复用上面的毛玻璃描边配方：1dp、`#66FFFFFF`（40% 白色）；黑底则用不透明黑边 `#FF000000`，与白底形成反差。

## 头部渐变（玻璃后面的环境色）

`bg_header_gradient.xml`：

```xml
<?xml version="1.0" encoding="utf-8"?>
<shape xmlns:android="http://schemas.android.com/apk/res/android"
    android:shape="rectangle">
    <gradient
        android:startColor="@color/accent"
        android:endColor="@color/accent_2"
        android:angle="135" />
</shape>
```

对应颜色：

```xml
<color name="accent">#FF2E86DE</color>
<color name="accent_2">#FF56A6F5</color>
<color name="white">#FFFFFFFF</color>
```

头部布局本身是 `LinearLayout`，背景为 `@drawable/bg_header_gradient`，左右 padding 20dp、上下 8dp，所以按钮贴着右侧、离屏幕边缘 20dp。

## 复现步骤

1. 复制 `bg_btn_header.xml` 到 `res/drawable/`。
2. 在头部容器（蓝色渐变背景内）放一个 `TextView`，绑定上述布局属性。
3. 背景引用 `@drawable/bg_btn_header`，文字白色，字号按所在容器调整。
4. 需要点击时保持 `clickable="true"` / `focusable="true"` 并绑 `setOnClickListener`。
5. 想要真实背景模糊时再考虑 Android 12+ 的 `RenderEffect` 或窗口 `FLAG_BLUR_BEHIND`；当前效果不依赖它们。
